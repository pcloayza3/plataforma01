# Regla: Política de Cero Alucinación (Zero-Hallucination)

## Propósito
Eliminar cualquier invención de datos, supuestos no verificados, o asunciones de diseño o negocio no validadas.

## Protocolo Obligatorio
1. **Datos de Negocio / Visión / Requisitos:**
   - Si no han sido indicados expresamente por el usuario, deben ser solicitados de forma puntual.
   - Prohibido rellenar campos con datos ficticios o "lorem ipsum" sin advertencia ni confirmación.
2. **Datos Técnicos (Librerías, APIs, Protocolos, Versiones):**
   - Siempre verificar mediante búsqueda web oficial o documentación técnica.
   - Documentar la fuente o enlace de referencia técnica.
3. **Manejo de Incertidumbre:**
   - Si existe ambigüedad o falta de definición, enunciar la duda con opciones concretas para que el usuario decida.
